Start with [What Is Sambee?](./getting-started/what-is-sambee/) for the definition or [What Can You Do With Sambee?](./getting-started/what-can-you-do-with-sambee/) for practical benefits.

- [Find and browse files](./find-and-browse-files/connect-to-an-smb-share/): Open a connection, select items, and find recent locations.
- [Organize and transfer files](./organize-and-transfer-files/copy-and-move-files/): Copy, move, upload, or download files.
- [Inspect ZIP archives](./organize-and-transfer-files/work-with-zip-archives/): Preview contents without extracting the whole archive.
- [View and edit files](./view-and-edit-files/view-images-and-read-documents/): Preview designs, edit text, or update Markdown tables.
- [Use desktop apps and local drives](./use-local-drives-and-desktop-apps/install-and-pair-the-companion-app/): Add optional Companion features.
- [Manage your account and preferences](./account-and-preferences/manage-your-account/): Control sessions and personal history.
- [Get help](./troubleshooting/common-user-problems/): Recover from access, saving, sharing, or transfer problems.
- [Check formats](./reference/supported-file-formats/): Find preview support and format limits.

For deployment and policy, use the [Admin Guide](../admin-guide/). For implementation, use the [Developer Guide](../developer-guide/).

Opening a file is different from selecting it for a bulk action. A focused row alone is not a selection. Each pane has its own selection; bulk actions use the active pane.

## Touch Selection

On phones, select an item from **More actions** or touch and hold its row. Tap more rows to change the selection, then use the pane's bottom selection controls.

Larger touch devices can use the same behavior without switching to the phone layout. See [File Browser Preferences](../../account-and-preferences/file-browser-preferences/#file-selection).

## Keyboard Selection

**Space** or **Insert** toggles selection on the focused row and moves down. See [Keyboard Navigation and Shortcuts](../keyboard-navigation-and-shortcuts/#selection-and-dual-pane-workflows) rather than a second shortcut list here.

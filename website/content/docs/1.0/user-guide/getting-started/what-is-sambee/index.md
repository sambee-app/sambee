## Sambee Turns Your Storage Into a Modern Workspace

Sambee is a browser-based workspace for files on SMB shares and local drives. Access your data from PCs, phones, and tablets. View images, read PDFs, and edit Markdown right in your browser. On the desktop, open any file in the natively installed apps you already use. Sambee saves your changes back to the original location.

See [What Can You Do With Sambee?](../what-can-you-do-with-sambee/) for examples.

## Browser-Based File Manager

Sambee can replace traditional tools like Windows File Explorer.

### Works on PCs, Phones, and Tablets

Sambee is optimized for large screens as well as for compact mobile devices.

### Supports SMB Shares and Local Drives

Sambee provides access to two types of storage: SMB file shares and your computer's local drives. You can move and copy files between them without restrictions, e.g. from your PC's local drive to a file share, or between different SMB shares.

Local drive access is requires Sambee Companion, a helper app that can be installed on your computer and acts as a small service your browser can talk to.

## View and Edit Files

### Image & PDF Viewers

Sambee is much more than a file manager. It includes a fast image browser with broad file type support, and a robust PDF viewer that opens even problematic PDFs. All of these work directly in the browser and do not require additional software.

### Markdown & Text Editors

Markdown files are rendered with rich formatting and can be modified efficiently with user-friendly WYSIWYG editing of Markdown tables.

Any kind of text file can be viewed and edited in the built-in text editor. It provides syntax highlighting for many file types, offers search & replace, and opens even very large files.

### Desktop App Integration

Sambee bridges the gap between the browser and the apps installed on your computer. It lets you open a file in its traditional desktop app directly from the browser. In other words, you can open Word, Excel, or Photoshop files in their respective native apps. When you are done editing, your changes are uploaded back to the original storage location. See [Edit Files in Desktop Apps](../../use-local-drives-and-desktop-apps/edit-files-in-desktop-apps/).

## Free & Open Source

Sambee is free and open source software designed for self-hosting as a Docker container. See [Deploy Sambee with Docker](../../../admin-guide/installation-and-deployment/deploy-sambee-with-docker/).

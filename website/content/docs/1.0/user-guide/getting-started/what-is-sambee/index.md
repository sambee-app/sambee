## Sambee Turns Your Storage Into a Modern Workspace

Sambee is a self-hosted, browser-based file manager for files on SMB network shares and local drives. Browse files, view images and PDFs, and edit text and Markdown in your browser. With optional Sambee Companion, access local drives and open network files in installed desktop apps, then upload your changes back to the original share without managing downloaded copies or choosing an upload destination.

See [What Can You Do With Sambee?](../what-can-you-do-with-sambee/) for practical outcomes.

## Browser-Based File Manager

Sambee can replace traditional tools like Windows File Explorer.

### Works on PCs, Phones, and Tablets

Sambee is optimized for large screens as well as for compact mobile devices.

### Supports SMB Shares and Local Drives

Your browser accesses SMB shares through the Sambee server. Companion is not required for this path, and your files stay on the storage you already use.

Local-drive access requires Sambee Companion on a supported desktop computer and browser trust approval. Local drives and desktop apps are not phone features.

## View and Edit Files

### Image & PDF Viewers

Sambee is much more than a file manager. It includes a fast image browser with broad file type support, and a robust PDF viewer that opens even problematic PDFs. All of these work directly in the browser and do not require additional software.

### Markdown & Text Editors

Markdown files are rendered with rich formatting and can be modified efficiently with user-friendly WYSIWYG editing of Markdown tables.

Supported text files can be viewed and edited in the built-in text editor, with syntax highlighting.

### Desktop App Integration

Open network files in Word, Excel, Photoshop, or another installed app through Sambee Companion. When your work is ready, use the explicit upload action to return changes to the original share. Closing the app alone does not upload an SMB edit. See [Edit Files in Desktop Apps](../../use-local-drives-and-desktop-apps/edit-files-in-desktop-apps/).

## Free & Open Source

Sambee is free and open source software designed for self-hosting as a Docker container. See [Deploy Sambee with Docker](../../../admin-guide/installation-and-deployment/deploy-sambee-with-docker/).

title = "Share Files on Phones and Tablets"
+++

On phones and tablets, Sambee integrates with your device's native sharing functionality so that you can send files to other apps.

## Share Stored Files

Choose **Share** from a file's action menu or the selection menu to prepare the stored files. When they are ready, tap **Share** to open your phone or tablet's share sheet. If you select several files, Sambee sends them together. It does not leave files out of your selection.

## Share from a Viewer or Editor

When you share from an image or PDF viewer, Sambee shares the version shown in the viewer. This can differ from the stored file if Sambee converted the image or prepared the PDF for viewing. PDF sharing includes the whole document, not just the current page. To share the original stored file, use **Share** in the file list.

For text and Markdown, choose what to share:

- **Share as file** sends the saved file. It does not save or include unsaved editor changes.
- **Share as text** sends the loaded text or current editor contents, including unsaved edits. For Markdown, it sends the Markdown text, not the formatted preview.

## If Sharing Is Unavailable or Fails

Even on phones and tablets, sharing support and accepted files depend on the browser and device. A file can be rejected after preparation. Sambee does not send text instead of a file automatically. Choose **Share as text** when that option is available and you want to send text.

If sharing is unavailable, including on desktop platforms, use **Download**. You can then send the downloaded file through another app on your device.

If sharing from a viewer fails, the recovery download gives you the same version you tried to share. For several prepared files, download each file separately. If Sambee cannot prepare a text or Markdown file, **Retry** prepares it again. You must then tap **Share** to open the share sheet.

### Get a Report for Support

Choose **Details** in the failure message to get a diagnostic report. It does not include file names, paths, text, file contents, or credentials. Sambee does not upload it automatically. If you cannot copy the report, select its text manually. Closing **Details** leaves the recovery actions available.

### Cancel or Check Delivery

Cancelling your phone or tablet's share sheet is not an error. A completed share request does not confirm delivery. Check the receiving app to confirm that it received the files or text.

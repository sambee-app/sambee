## Share a Location

Copy the current Sambee address to share a file or folder location. This link **does not grant access**. Recipients need access to the site, connection, and file; local-drive links also require a paired desktop Companion with that drive available.

Opening or closing viewers and editors, changing gallery images, and navigating settings update the address. Browser history does not undo saved changes or restore discarded edits. See [unsaved-change recovery](../../view-and-edit-files/recover-unsaved-edits/).

## Share Stored Files

On phones, **Share** in an item's action menu or the selection menu prepares the stored files. When preparation finishes, tap **Share** to open the device's share sheet. Multiple files are submitted together; Sambee does not silently reduce the selection.

## Share from a Viewer or Editor

Image and PDF viewer sharing uses the **displayed resource**, which can be a converted image or normalized PDF. PDF sharing includes the whole displayed document. File-list sharing uses the original stored file instead.

Text and Markdown sharing has two choices:

- **Share as file** uses the saved file without saving editor changes first.
- **Share as text** uses the loaded text or current editor contents, including unsaved edits. Markdown is shared as source, not rendered HTML.

## If Sharing Is Unavailable or Fails

Support and accepted attachments depend on the browser and device. An attachment can be rejected even after a capability check. Sambee does not silently substitute text; choose **Share as text** explicitly when available.

Use **Download** and share from your device's file app. After viewer sharing fails, the recovery download uses the same displayed resource. For several attachments, download each prepared file. If text or Markdown attachment preparation fails, **Retry** prepares it again without opening the share sheet automatically.

Use **Details** in failure feedback to obtain a diagnostic report for support. It excludes file names, paths, text, contents, and credentials, and is not uploaded automatically. If copying is unavailable, select the report text manually. Closing Details keeps recovery actions available.

Cancelling the device's share sheet is not an error. Completion of a browser share request does not confirm what the receiving app received.

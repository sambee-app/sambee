Opening a file is different from selecting it for a bulk action. A focused row alone is not a selection. Each pane keeps its selection when you switch panes; bulk actions use the active pane.

## Desktop Mouse Selection

With touch selection off, click the name to open an item or its icon to select it. After the first selection, icons become selection controls. **Shift**-click an icon to add a range without losing earlier selections. Mouse and keyboard selection share the range anchor.

Clicking outside the icon or in empty list space clears selection **without opening the item**; click again to open it. **Escape** also clears selection. Sorting or starting File Search clears the active pane's selection.

## Touch Selection

On phones, select from **More actions** or touch and hold a row. Tap additional rows to change the selection, then use the pane's bottom selection controls. Larger touch devices can use this behavior too; see [File Browser Preferences](../../account-and-preferences/file-browser-preferences/#file-selection).

These **Settings > File Browser** options apply to your browser preferences, not server policy.

## File Selection

**Automatic** enables touch selection on larger devices with a coarse primary pointer, such as a tablet. **Always on** enables it on all larger layouts; **Off** disables it there. Phone layouts always provide touch selection. See [Select Files and Folders](../../find-and-browse-files/select-files-and-folders/).

## Shortcut Hints

**Auto** shows hints on larger layouts and after keyboard use in the current compact-layout session. **Always** shows them in all layouts; **Never** hides shortcut labels without hiding Quick Bar status.

## Clear Personal History

Clear file history under **File Search** or directory history under **Directory Navigation**. This removes history records, not files or folders. History is private to your account. Server retention and exclusions are [administrator policy](../../../admin-guide/reference/configuration-file-reference/#file-search-and-history-policy).

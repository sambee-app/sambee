## Share a Folder Location

A link to a Sambee folder points to its location; it does not grant access. Recipients need access to the Sambee site, connection, and folder. Local-drive links also require the recipient's supported desktop Companion path with that drive available.

## Share a File from a Phone or Tablet

Sambee's file-sharing action is available only on mobile platforms: phones and tablets. It is not available on desktop platforms. Support also depends on your mobile browser and device.

If sharing is unavailable, use **Download** and send the file through another app on your device. Downloading or sharing a copy does not change the original file's access permissions.

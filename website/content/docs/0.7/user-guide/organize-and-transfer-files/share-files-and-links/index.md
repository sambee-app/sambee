## Share a Folder Location

A link to a Sambee folder points to its location; it does not grant access. Recipients need access to the Sambee site, connection, and folder. Local-drive links also require the recipient's supported desktop Companion path with that drive available.

## Share a File from a Phone

Sharing network files depends on your browser and device. If sharing is unavailable, download the file and share it from your device's file app. Downloading or sharing a copy does not change the original file's access permissions.

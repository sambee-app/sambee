Opening a file is different from selecting it for a bulk action. A focused row alone is not a selection. Copy and move commands use the selected items in the active pane, not the other pane's selection.

With keyboard focus on a row, **Space** or **Insert** toggles its selection and moves down. See [Keyboard Navigation and Shortcuts](../keyboard-navigation-and-shortcuts/#selection-and-dual-pane-workflows) for range and whole-list selection. Use [Copy and Move Files](../../organize-and-transfer-files/copy-and-move-files/) for transfers.

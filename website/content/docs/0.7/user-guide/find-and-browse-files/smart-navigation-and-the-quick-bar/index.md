The **Quick Bar** finds directories and commands without clicking through menus.

## Jump to a Directory

Press **Ctrl + K**, then enter part of a directory name. Matches come from the current connection. Choose a result to open that directory.

## Filter the Current Folder

**Ctrl + Alt + F** filters the active folder by file or directory name. It is not a global file index and does not search file contents.

## Find a Command

Use **Ctrl + P** or **F1** to search commands by name. See [Keyboard Navigation and Shortcuts](../keyboard-navigation-and-shortcuts/) for keyboard help, or [Select Files and Folders](../select-files-and-folders/) for bulk actions.

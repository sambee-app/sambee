title = "What Can You Do With Sambee?"
+++

Keep your files where they are and do more with them. Preview design files from your phone, change a Markdown table without editing its markup, or open a network file in your favorite desktop app.

## Give Your Existing Storage a Modern Workspace

Keep project files on your NAS or Windows file server, without migrating to a cloud library. [Open an SMB connection](../../find-and-browse-files/connect-to-an-smb-share/). With Companion, [bring local drives into the workspace](../../use-local-drives-and-desktop-apps/access-local-drives/) and [copy files between drives and shares](../../organize-and-transfer-files/copy-and-move-files/).

## Preview Design Files from Your Phone

Check a Photoshop design or HEIC photo on a network share without installing its desktop app or downloading it first. Browse a large image collection, including formats your browser cannot display on its own. See [View Images and Read Documents](../../view-and-edit-files/view-images-and-read-documents/) and [Supported File Formats](../../reference/supported-file-formats/).

## Change Markdown Tables Without Fighting the Markup

Update a project checklist or comparison table in its rendered table view, instead of aligning pipes and rows in source text. Your document stays a Markdown file in its existing storage. See [Edit Markdown](../../view-and-edit-files/edit-markdown/).

## Stop Digging Through Folder Trees

Type part of a directory name and jump to the matching folder. Use [smart navigation](../../find-and-browse-files/smart-navigation-and-the-quick-bar/) to reach a project quickly, and [two panes](../../find-and-browse-files/dual-pane-mode/) to compare folders on desktop.

## Edit in Your Desktop Apps. Return Changes to the Original Share.

Work on network files in Word, Photoshop, LibreOffice, or another installed app. Sambee Companion handles the file handoff and uploads your finished edits back to their source, so you do not have to manage a separate download-and-upload workflow. See [Edit Files in Desktop Apps](../../use-local-drives-and-desktop-apps/edit-files-in-desktop-apps/).

## Start with a Preview

[Preview a design or photo](../../view-and-edit-files/view-images-and-read-documents/), even with read-only access and without Companion. If no connection is available, see [connection guidance](../../find-and-browse-files/connect-to-an-smb-share/).

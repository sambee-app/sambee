## Browser-Based File Manager

Sambee is a self-hosted, browser-based file manager for files on SMB network shares and local drives. Browse files, view images and PDFs, and edit text and Markdown in your browser. With optional Sambee Companion, access local drives and open network files in installed desktop apps, then upload your changes back to the original share without managing downloaded copies or choosing an upload destination.

Sambee can replace traditional tools like Windows File Explorer. Single-pane and dual-pane views bring your existing storage into one workspace.

See [What Can You Do With Sambee?](../what-can-you-do-with-sambee/) for examples.

### Supports SMB Shares and Local Drives

Your browser accesses SMB shares through the Sambee server. Companion is not required for network shares.

Browse network files from PCs, phones, and tablets. Local-drive access requires Sambee Companion on a supported desktop computer and browser trust approval; it is not a phone feature.

## Image and PDF Viewer, Markdown Editor

Sambee is more than a file manager. It is built for speed and includes a fast image browser with broad file type support, a Markdown editor, and a PDF viewer. All of these work directly in the browser and do not require additional software, except Companion for local-drive access.

Edit supported text files directly in storage, or change Markdown tables in their rendered view without aligning markup. See [View and Edit Text Files](../../view-and-edit-files/view-and-edit-text-files/) and [Edit Markdown](../../view-and-edit-files/edit-markdown/).

## Desktop App Integration

Open network files in Word, Excel, Photoshop, or another installed app through Sambee Companion. When your work is ready, explicitly upload the changes back to the original share. Closing the app alone does not upload an SMB edit. See [Edit Files in Desktop Apps](../../use-local-drives-and-desktop-apps/edit-files-in-desktop-apps/).

Markdown files are opened in Sambee's [Markdown viewer](../view-images-and-read-documents/). From there, you can seamlessly switch to a full-fledged Markdown editor.

## Entering Edit Mode

Use **Edit** or **E** in the Markdown viewer to edit source. Tables can be changed in their rendered table view: edit cells and add or remove rows and columns without aligning Markdown markup. The result stays a Markdown file in its original storage.

## Saving Changes

A small indicator next to the file name shows whether the document has unsaved changes. Click the save icon or press <kbd>Ctrl</kbd> + <kbd>S</kbd> at any time to save the current state of the document.

## Leaving Edit Mode

Click the X icon or press <kbd>Esc</kbd> to leave the Markdown editor. If there are unsaved changes, you are asked whether to save them.

Editing requires write access and a file lock. See [File Locking and Conflict Resolution](../file-locking-and-conflict-resolution/) if editing is unavailable. For other text formats, see [View and Edit Text Files](../view-and-edit-text-files/).

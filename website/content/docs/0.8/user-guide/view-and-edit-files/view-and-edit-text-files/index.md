Edit supported text files in their existing storage, without downloading a separate copy. The text editor writes back to the source file; read-only storage cannot be edited. Local files require [Companion access](../../use-local-drives-and-desktop-apps/access-local-drives/).

Use the text editor for supported text formats and [Edit Markdown](../edit-markdown/) for rendered Markdown tables. See [Supported File Formats](../../reference/supported-file-formats/) if a file opens in another viewer.

## Save to Storage

**Save** writes your changes to the original file. Changes not yet saved are not in storage. Editing obtains a file lock; if the file is locked or your session loses its lock, see [File Locking and Conflict Resolution](../file-locking-and-conflict-resolution/). Keep your draft until you can save it or preserve a separate copy.

Leaving with unsaved changes asks whether to save them. Do not treat browser navigation as an undo of changes already saved.

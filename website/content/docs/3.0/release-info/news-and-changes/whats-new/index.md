## Tabs

Open multiple tabs for the locations you need most often. Tabs are available in single-pane as well as in dual-pane mode and in all screen sizes, from phone to desktop.

## System Health Monitoring

Sambee now shows the system health status in the top-right corner. Clicking the icon opens a dialog with detailed health information that covers the server, the Sambee container and connected storage.
